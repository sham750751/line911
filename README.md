# Sar Expo 74

Однопользовательский Android-прототип для закупки товаров в Китае, перемещения партий и продаж в России. Пакет ru.sarexpo.trade, версия 0.2.0, Android 8+ с актуальным Android System WebView. Приложение автономное, без сетевых разрешений.

## Работа
Кнопка «Моя база» открывает переключение между рабочей и демонстрационной базами и резервное копирование. Рабочая база изначально пуста. Введи поставщика, курс, товары, доставку и оплаченную сумму. Из «Склада» выбери позицию для продажи, перемещения или регистрации брака. В «Долгах» можно внести частичную оплату. Принятая замена возвращается в доступные остатки. При списании согласованная компенсация учитывается в рублях и отдельно погашается платежом.

Закупка и долг поставщику ведутся в юанях. Расходы на партию вводятся в рублях и распределяются пропорционально закупочной стоимости. Прибыль учитывает выручку, себестоимость проданного и списанного товара и согласованные компенсации. Данные хранятся на устройстве. Сделай JSON-копию перед удалением приложения. Экспорт и восстановление используют системный выбор файла.

## Проверка и сборка
Запусти `node tests/ledger.cjs` и `bash build.sh` с Android SDK Platform 35, Build Tools и JDK. Подписанный APK опубликован в dist. Пакет 0.1.0 использовал отдельную временную подпись. Обе версии можно установить одновременно и перенести рабочую базу через JSON. В новой версии возврат доступен из продажи в журнале. Сначала уменьшается долг клиента, затем создаётся обязательство вернуть оставшуюся сумму. При экспорте в старую версию операции возврата не поддерживаются.

Результат сборки находится в dist. Для повторяемой подписи задай SAR_SIGN_KEY (путь к keystore) и SAR_SIGN_PASS (пароль). Без ключа результат остается неподписанным. Ключ распространяемой версии хранится отдельно от репозитория. GitHub Actions проверяет подпись APK и запускает отдельную проверку установки на эмуляторе.
